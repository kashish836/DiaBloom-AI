# DiaBloom AI

A Diabetes Risk Prediction Web Application built using Machine Learning, Flask, and Scikit-Learn.

## Overview

DiaBloom AI predicts diabetes risk based on health-related input parameters. The application combines a machine learning model with a Flask web interface to provide instant predictions through a user-friendly experience.

## Features

* Diabetes risk prediction using a trained machine learning model
* Interactive web interface built with Flask
* Responsive and modern UI design
* Real-time prediction results
* End-to-end machine learning deployment project

## Technology Stack

* Flask

* CSS

* GitHub

## Dataset

The model is trained on the Pima Indians Diabetes Dataset.

### Input Features

* Pregnancies
* Glucose
* Blood Pressure
* Skin Thickness
* Insulin
* BMI
* Diabetes Pedigree Function
* Age
